Task 9 – Responsive Laundry Services Landing Page
📌 Project Overview

This project is a responsive Laundry Services landing page created using HTML5 and CSS3. It features a clean navigation bar, an attractive hero section, interactive buttons, and a responsive layout that adjusts to different screen sizes.

The main goal of this project is to practice CSS Flexbox, responsive web design, media queries, and CSS hover transitions.

🚀 Features
Navigation Bar: Contains Logo, Home, Services, About Us, Contact Us, and Username button.
Hero Section: Includes an attractive heading, description, and call-to-action button.
Highlighted Text: Uses a different color to highlight important heading text.
Laundry Image: Displays a laundry-related image beside the hero content.
Responsive Design: Adapts to desktop, tablet, and mobile screen sizes.
Hover Effects: Navigation links have interactive hover effects.
Button Animation: Uses CSS transitions and skew transformation on hover.
Flexbox Layout: Uses CSS Flexbox to arrange and align elements.
🛠️ Technologies Used
HTML5 – To create the webpage structure.
CSS3 – To style the webpage.
CSS Flexbox – To create flexible layouts.
Media Queries – To make the website responsive.
CSS Transitions – To create smooth hover animations.
CSS Transform – To apply skew effects to the button.

📱 Responsive Design

The website supports different screen sizes using CSS media queries.

Screen Size	Layout
Desktop	Horizontal navigation and side-by-side hero section
Tablet (768px)	Adjusted font sizes, padding, and spacing
Mobile (480px)	Navigation links hidden and hero section stacked vertically
Small Mobile (320px)	Further adjustments to font sizes and button spacing
✨ CSS Effects
1. Navigation Hover Effect

Changes the background color and adds rounded corners when hovering over navigation items.

2. Button Hover Animation

Uses the CSS transform: skew(25deg) property to create a skew effect when hovering over the booking button.

3. Smooth Transition

Uses transition: 0.6s ease to make the button animation smooth.
